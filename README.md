# Book Tracker - Трекер прочитанных книг
## Описание программы
Book Tracker - это графическое приложение на Python для отслеживания прочитанных книг. Программа позволяет:
- Добавлять книги с указанием названия, автора, жанра и количества страниц
- Просматривать список всех добавленных книг в удобной таблице
- Фильтровать книги по жанру и количеству страниц
- Удалять книги из списка
- Сохранять и загружать данные в формате JSON
## Требования
- Python 3.6 или выше
- библиотека Tkinter 
## Инструкция по запуску
1. Скачайте файл `cod.py`
2. Откройте терминал/командную строку в папке с программой
3. Запустите команду:
   python cod.py
